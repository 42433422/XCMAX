## 这是什么

XCAGI（修茈）是面向中小企业的**私有化桌面 AI 工作平台**：把重复业务交给「AI 员工」，业务数据装在您自己的电脑里，而不是交给公共云代管。

它能帮你做这些事：

- 用日常语言一句话派活，让 AI 员工拆任务并交付可复核的结果
- 把 Excel 等业务表拖进「数据对接中心」，选模板后写入知识库与业务库
- 按行业需要安装扩展（Mod），把通用宿主变成更贴近本行的工具
- 在审批中心处理入库相关确认与撤回

适合制造业、园区、贸易等对数据保密有要求、希望「AI 帮忙干活」又不想把核心数据交给公共云平台的团队。

## 安装与首次打开

企业用户请从官网下载桌面版安装包：<https://xiu-ci.com>。也可先用在线体验入口感受产品：<https://xiu-ci.com/download>。

### 推荐步骤

1. **安装桌面版**  
   运行供应商提供的 XCAGI 安装程序（Windows / macOS）。安装过程中请先退出旧版（含右下角托盘图标），以免文件被占用。

2. **完成首次设置**  
   首次打开会进入首次设置：填写公司名称 → 选择或描述行业 → 确认配置方案 → 进入工作空间。行业名称用于准备对应能力，不会自动增加额外授权。

3. **装好通用能力（如提示）**  
   若提示扩展未就绪，打开「能力库 / 扩展市场」，按提示一键装齐通用包。装好后「智能对话」应可正常使用。

4. **确认数据在本机**  
   桌面版业务数据保存在本机用户数据目录。供应商不代管您的业务库；请定期自行备份重要资料。

具体安装文件名、系统要求与交付边界以供应商随包说明为准。未签名或候选构建是否开放自动更新，也以供应商当面交付约定为准。

## 主界面导览

左侧是常用入口。装了行业扩展后，部分菜单名称可能变成更贴近本行的叫法（例如「产品管理」「出货记录」），下面按通用宿主名称说明。

| 入口 | 做什么 |
|------|--------|
| **智能对话** | 找小 C 办事、下指令、看任务进度（主入口） |
| **信息** | 联系已安装的 AI 同事或专属客服，一对一聊 |
| **智能生态** | 智慧分析等应用入口 |
| **知识库** | 查看企业知识、资料来源与长期记忆 |
| **数据对接中心** | 上传业务文件，识别、预览并确认写入业务数据 |
| **审批中心** | 处理审批与自动入库批次；可撤回整批入库 |
| **能力库** | 浏览、安装与管理扩展（Mod） |
| **模板库** | 浏览与管理已保存模板；新导入请走数据对接中心 |
| **系统设置** | 账号、偏好与本机相关设置 |

业务对象、业务单据、组织管理、模板与打印等菜单，会随已安装扩展与行业方案出现；没有对应扩展时可能看不到或名称不同。

## 日常怎么用

### 用对话派活

1. 打开侧栏「智能对话」。
2. 用日常语言说明目标。例如：「整理上周考勤台账，标出异常并导出报表。」不必记菜单路径。
3. 关注进度与结果。AI 员工会拆任务并给出可复核结果；需要确认时，按界面提示人工复核后再继续。
4. 善用回复下方建议。部分版本在 AI 回复下方提供三条可点选建议，点选后填入输入框草稿，**不会自动执行**。

对话区支持附件时，可按界面提示添加 Excel、图片或 PDF。若当前安装包暂不支持拖入，请改用界面上的上传入口或先走数据对接中心。

### 数据对接：把表格变成可用业务数据

「数据对接中心」用来把业务 Excel 等文件归档、分类并选模板保存。设计路径是：

**丢文件 → 开始处理 → 选模板 → 写入知识库与对应业务库**；需要时在审批中心撤回。

1. 侧栏进入「数据对接中心」。
2. 把文件拖到底部对话框，或按提示选择文件（常见为 Excel）。
3. 点「开始处理」。系统归档原件并做分类核对；请按界面确认分类、片段等信息。
4. 处理完成后弹出候选模板（三张 A4 表格卡片）。选好后保存所选模板。
5. 保存后，系统按实际进度写入知识库与对应业务域。可在进度提示中查看阶段，不要假定「一点就立刻全部写完」。
6. 审批中心里可查看「数据对接自动入库」批次；未完成依赖冲突时，可撤回整批入库。

模板库只负责浏览和管理已保存模板；**新文件导入请走数据对接中心**，避免新旧入口混用。

### 查已入库数据与知识问答

- 在「知识库」查看已沉淀的企业知识与资料来源
- 在智能对话中用自然语言询问已导入内容（例如某类单据、异常汇总）
- 在业务菜单（如业务记录、业务对象等，名称随行业扩展变化）核对写入结果

## 数据与安全

XCAGI 桌面版的核心约定是：**业务数据留在您企业自己的电脑上**，由您本地使用与保管；供应商不代运营您的业务库。

| 要点 | 说明 |
|------|------|
| **存放位置** | 本机用户数据目录（含业务库、日志、备份等） |
| **业务原件归档** | 数据对接产生的原件归档存放在稳定的本机归档区，内容加密保存，并受归档配额约束 |
| **默认归档空间** | 未另行配置时，默认约 **10GB** 归档配额；用满后需清理或由管理员提高配额后再继续归档 |
| **备份建议** | 重要业务库与归档请按贵司制度自行备份；升级或重装前先确认旧版已退出 |
| **诊断与支持** | 向供应商反馈问题时，可按界面导出已脱敏的诊断包；请勿在聊天里粘贴账号密码或密钥 |

> **请注意**：本说明书不包含任何账号口令、接口密钥或内部运维步骤。账号由贵司自行管理；密钥与授权材料只通过供应商约定渠道交接。

## 常见问题

**找不到数据对接中心？**  
看左侧侧栏是否显示该名称；若只有旧书签，打开后应自动转到新入口。仍没有时，检查首次设置是否完成、通用扩展是否已装齐。

**菜单名称和说明书不一致？**  
正常。安装行业扩展后，产品、客户、出货等菜单会改成行业用语；对话、知识库、数据对接中心等通用入口通常仍在。

**点了开始处理却提示配额？**  
归档需要可用配额。默认约 10GB；不足时请清理旧归档或联系管理员调整配额。

**选了模板但业务库还没有？**  
入库按阶段进行。请等待进度完成，再到知识库或对应业务菜单核对；必要时在审批中心查看该批次状态。

**安装时提示文件被占用？**  
请先完全退出旧版 XCAGI（含托盘），再重试安装。不要删除数据库来「腾地方」。

**智能对话不能拖文件？**  
以当前安装包界面能力为准。可改用上传按钮，或把表格放到数据对接中心处理。

**手机能不能用？**  
产品线包含移动协同能力，交付范围与账号开通以供应商合同与随包说明为准；本说明书以桌面版为主。
