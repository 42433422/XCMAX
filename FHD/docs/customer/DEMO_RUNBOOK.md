# 客户演示走查清单与对外口径卡

> **读者**：售前演示负责人、项目负责人、客户成功。
> **目标**：客户第一次真实使用的前 15 分钟（安装 → 首次启动 → 扫码绑定 → 与 AI 员工说上第一句话）不翻车、不造假、不超承诺。
> **配套**：产品级验收标准见 [`../guides/PRODUCT_POLISH_CHECKLIST.md`](../guides/PRODUCT_POLISH_CHECKLIST.md)；对外数字唯一来源见 [`../CLAIMED_VS_ACTUAL.md`](../CLAIMED_VS_ACTUAL.md)。

---

## 一、演示前 24 小时：动线走查（必须全部亲手跑通）

按客户视角完整走一遍，任何一步失败即视为演示阻塞，先修复再演示。

### 1. 安装与首次启动

- [ ] 在干净的 Windows 机器上运行安装包，桌面出现 XCAGI 图标。
- [ ] 首次启动开屏 ≤ 12 秒进入登录或引导页；若触发兜底跳过，记录日志排查。
- [ ] 引导页「宿主能力包」检测通过（`deliverable: true`）。

### 2. 登录与手机绑定（P0 路径一）

- [ ] 密码登录、扫码绑定、设备码绑定三条路径全部跑通。
- [ ] 绑定成功后立刻请求员工列表、消息列表、个人页，**0 个非预期 401/403**。
- [ ] 手机切 5G（离开局域网）后再次请求同一组接口，确认自动走服务器中继。
- [ ] 故意用过期二维码扫码：提示必须是「二维码已过期，请刷新」，不允许出现
      `HTTP 401` / `Unauthorized` / `请求失败：401` 等原始文案。
- [ ] 断网发起登录：提示必须是「无法连接服务器，请检查网络」类产品文案。

### 3. 员工通讯录三端一致（P0 路径二）

- [ ] 管理端信息页、手机端消息页、手机端 AI 员工页展示**同一批员工**（数量、名称一致）。
- [ ] 本机未安装的员工必须显示「编制员工 · 未安装」，状态为「未安装」，
      点击发送时提示先安装员工包——**不允许假装在线**。
- [ ] 员工编制图谱中「在岗」员工数与本机 `mods/_employees/` 实际安装数一致。

### 4. 超级员工 Codex（P1 路径四）

- [ ] 电脑执行端在线时：派一条任务，看到「思考中...」→ 执行进度 → 真实结果回写。
- [ ] **断开电脑执行端**再派任务：手机端/管理端必须显示「任务已入队，电脑执行端当前
      离线」或「等待电脑执行端上线」——**不允许显示假成功**。
- [ ] 任务完成后能展示真实产物（commit、日志、安装包路径任一）。

### 5. 演示红线（任何一条出现即中止该功能演示）

- 界面出现英文异常堆栈、原始 HTTP 状态码文案。
- 员工「在线」但点击后不能对话或返回占位假回复。
- 桌面端离线但任务显示「执行中/已完成」。

## 二、对外口径卡（对客户话术纪律）

### 数字口径

| 规则 | 说明 |
|------|------|
| **唯一来源** | 一切对外数字只引用 [`CLAIMED_VS_ACTUAL.md`](../CLAIMED_VS_ACTUAL.md) 自动生成的对照表 |
| **禁止口径** | 该文档「已退役口径」黑名单中的任何数字（历史上曾因误报对外后撤回） |
| **覆盖率** | 说「后端行覆盖 85%（实测）」，不说「90%+」（那是目标值） |
| **SLO/性能** | staging 7 天实跑（Round-2）出结果前，只说「压测验证中」，不给承诺值 |

### 各端交付等级口径

| 端 | 对外口径 | 依据 |
|----|----------|------|
| Windows 桌面（企业版） | **可交付**，主交付形态 | 发版链路 + 回滚 + 自动更新完备 |
| Web 管理端 | **可交付** | 随桌面/自托管交付 |
| Android App | **签约级** | `VERSION.md` 交付等级表，有实测背书 |
| iOS App | **「功能完备，真机验证中」** | 缺 Apple 签名/APNs/真机 QA，不承诺档期 |
| 鸿蒙 App | **「企业版验证中」** | Mod WebView 仍占位，缺真机 QA |
| Flutter | **不对外提及** | 内部 POC，非交付线 |

### 版本口径

- 全产品线版本统一为 **v10（10.0.0）**；对客户不承诺 v10.x / v11 时间表。
- 功能迭代以「v10 线内更新」表述，具体见 `CHANGELOG.md` Unreleased 节。

### 能力边界话术

- 客户问「员工现在能干活吗」：以界面「在岗/未安装」状态为准回答，当场点开验证。
- 客户问「手机不在公司能用吗」：答「走服务器中继，需要企业部署中继服务」，并演示 5G 切换。
- 客户问「AI 全自动化」：答「多设备调度已上线，全自动闭环在灰度验证中」，不演示未验证链路。

## 三、演示环境准备清单

- [ ] 演示机提前 1 天完成安装并跑完第一节全部走查项。
- [ ] 手机端提前完成绑定，确认中继连通。
- [ ] 准备一名「未安装员工」用于演示诚实状态（体现产品可信，而非隐藏）。
- [ ] 桌面执行端断开/重连各演练一次，确认状态提示符合预期。
- [ ] 备好回滚方案：演示包版本、上一稳定版本安装包、`CUSTOMER_SUPPORT.md` 诊断流程。
