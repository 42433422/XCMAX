## 验收通过标准

1. **全部用例 ✅**：5 个阶段所有用例在至少 3 台机器上全部通过
2. **平台覆盖**：Win10 / Win11 / macOS 至少各 1 台
3. **架构覆盖**：macOS 需 arm64 + x64 各 1 台（或 universal 包验证）
4. **无 P0/P1 缺陷**：验收中发现的 P0/P1 缺陷必须修复并复测
5. **性能达标**：首次启动 P95 ≤ 60s，后续启动 P95 ≤ 15s（参考启动基线报告）
6. **回滚验证**：阶段 4.7 必须实际触发一次回滚，验证 rollback-applied.json 生成

## 附录：诊断信息收集

每台机器验收完成后，导出诊断包（菜单 → 导出诊断包）并上传到共享盘：
- 路径：`/Shared/XCAGI-acceptance/<机器编号>/xcagi-support-<timestamp>.zip`
- 内容：后端日志、Electron 日志、updater-events.jsonl、rollback-*.json（如有）

诊断包包含：
- `electron-backend.log`：后端 stdout/stderr
- `updater-events.jsonl`：更新事件流水
- `rollback-marker.json` / `rollback-applied.json`：回滚状态（如有）
- `frontend-cache-version.txt`：前端缓存版本
- 后端 `/api/desktop/support-bundle` 返回的完整诊断 zip
