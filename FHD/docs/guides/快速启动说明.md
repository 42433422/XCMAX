# XCAGI 1.0.0.5 稳定版快速启动指南

> 稳定产品版本：1.0.0.5 | 更新日期：2026-11-12

XCAGI 1.0.0.5 支持**桌面版**和 **Web 版**两种运行模式。

---

## ⚡ 快速启动（桌面版）

### 方式 1：一键启动脚本（推荐）

```cmd
# Windows 桌面版（在 FHD 目录下）
双击 start-dev.bat
```

> 说明：`quick-start.bat` 不在 FHD 根目录，位于 `FHD\XCAGI\quick-start.bat`（转发到同目录的 `start-dev.bat`）；桌面版直接双击 FHD 根目录的 `start-dev.bat` 即可。

### 方式 2：手动启动

```bash
# 1. 进入项目目录
cd e:\FHD

# 2. 启用桌面模式
set XCAGI_DESKTOP_MODE=1

# 3. 启动服务（默认端口 5000）
python run.py

# 4. 访问应用
# 前端: http://localhost:5173（开发服务器）
# API:  http://localhost:5000
```

---

## ⚡ 快速启动（Web 版 / Docker）

### 方式 1：Docker Compose

```bash
# 1. 进入项目目录
cd e:\FHD

# 2. 复制 Docker 环境变量文件
copy .env.fhd-docker.example .env.fhd-docker

# 3. 编辑 .env.fhd-docker，配置 DATABASE_URL / SECRET_KEY

# 4. 构建并启动（FastAPI + Redis）
docker compose -f docker/docker-compose.fhd-full.yml --env-file .env.fhd-docker up -d --build

# 5. 查看状态
docker compose -f docker/docker-compose.fhd-full.yml ps

# 6. 查看日志
docker compose -f docker/docker-compose.fhd-full.yml logs -f fhd-api
```

## ❓ 常见问题

### Q1: 端口被占用

**解决**：
```bash
# 查看占用端口的进程（Windows）
netstat -ano | findstr :5000
taskkill /PID <PID> /F

# 或修改启动脚本中的端口
```

### Q2: 服务启动后立即停止

**解决**：
```bash
# 查看详细日志
python run.py
# 检查 .env 配置
# 确认 Python 版本 >= 3.10
python --version
```

### Q3: 桌面模式不工作

**解决**：
```bash
# 确认环境变量已设置
echo %XCAGI_DESKTOP_MODE%
# 应该输出 1

# 检查是否使用 SQLite（桌面模式应使用 SQLite）
```

### Q4: 前端无法访问

**解决**：
```bash
# 开发模式：确认前端开发服务器已启动
cd frontend
npm run dev

# Docker 模式：检查 API 容器状态
docker compose -f docker/docker-compose.fhd-full.yml ps fhd-api
docker compose -f docker/docker-compose.fhd-full.yml logs fhd-api
```

## 🔄 升级到 v7.0

如果从旧版升级：

```bash
# 1. 备份数据
# Docker 模式
docker compose -f docker/docker-compose.fhd-full.yml down
docker run --rm -v fhd-redis-data:/data -v $(pwd)/backup:/backup alpine \
  tar czf /backup/fhd-redis-data-backup.tar.gz /data

# 2. 更新代码
git pull origin main

# 3. 更新 .env.fhd-docker 配置

# 4. 重新构建
docker compose -f docker/docker-compose.fhd-full.yml build --no-cache

# 5. 启动服务
docker compose -f docker/docker-compose.fhd-full.yml --env-file .env.fhd-docker up -d

# 6. 运行数据库迁移
docker exec fhd-api alembic upgrade head
```
