## 我们在做什么？

**XCAGI** 是面向企业的桌面产品。企业用本地 ERP 管理业务数据，通过对话把任务交给 AI 员工 **小C**，再按需安装行业 Mod，为它补充工具、流程和模板。**XCMAX** 是本项目的工程仓库，包含桌面客户端、业务后端、行业模块和平台运营代码。

我们也在用这套产品建设一家 AI 原生公司：先让小C在公司内部做真实工作，再把自己用过、验证过的小C能力交付给其他企业。我们把接单、审批、执行、核验和交付连起来，用实际结果和反馈改进产品。企业仍然掌握数据访问和关键操作的决定权。

完整流程仍在建设和验证，不能把代码、实验功能或候选包当成已交付能力。查已具备的功能和可用范围，请以对应版本、部署方式和账号权限为准。

## 一项业务怎么交付？

以整理考勤台账为例，这是一条我们在建设和验证的业务流程：

1. **接任务**：员工在对话里说清统计范围、业务规则和输出要求；口径不清时，小C 先问。
2. **按权限执行**：小C 读取账号有权访问的花名册和考勤表。需要审批的写入操作，等批准后才执行。
3. **核验并交付**：将结果与原表对照，把台账、异常明细和处理记录交回；没有核验过的结果不算完成。
4. **记录反馈**：把修正和异常保留下来，用于改进下一次处理和后续产品版本。

本地 ERP 提供业务记录和操作入口；AI 员工负责读取、规划与执行；行业 Mod 按场景补充工具、流程和模板。可用能力取决于部署方式、账号权限和已安装模块。

## 使用哪一端？

| 入口 | 用途 |
| --- | --- |
| **Windows / macOS 企业桌面端** | 企业业务主入口，用于处理 ERP 数据、对话派任务和使用已授权的行业 Mod。可用安装包与签名状态见[官方下载](https://xiu-ci.com/download)。 |
| **Flutter 移动端（Android / iOS）** | 桌面业务的配套客户端源码，面向移动查看与协作。Android 为实验渠道；iOS 是否可下载以 App Store 实际上架为准。源码或候选包不代表正式开放。 |
| **Web 平台管理端** | 用于平台运营与配置，不等同于企业桌面宿主，也不替代企业业务入口。 |

支持本地部署。平台模型、外部系统、模块下载或更新等能力可能需要联网，具体以所选部署方式和实际启用的集成为准。
