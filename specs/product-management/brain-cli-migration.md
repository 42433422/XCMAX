# 智脑集成迁移到终端

2026-09-05 用户要求将“智能集成”改成 CLI，移除前端展示。当前产品对应入口为“智脑集成”（宿主 `/brain`、Planner Mod `/mod/xcagi-planner-bridge/brain`）。本变更纳入产品改进目标；已完成的首用与标签修复单独保存在 `4c4fe63ec0cf60bf90823582cd40f4b0dfc04f79`。

## 产品范围

- 移除独立智脑页面、菜单、物理前端模块及构建注册。两个旧页面地址回到正常首页，不新建终端网页。
- 提供 `xcagi-brain` 命令及 `python -m app.cli.brain` 入口，支持单次命令和交互式终端。
- 迁移现有对话、状态查询、接口目录、代码读取、修改提案、差异查看与明确应用操作。继续通过正常服务 API 执行，不直调业务函数绕过身份或 P2 校验。
- 主对话和智能生态仍是正常产品功能。现有只读运维 `xcmax-terminal` 有独立的 MODstore 管理边界，不与企业业务 CLI 混为一套身份。

## 当前发现与实现约束

原页面请求的 `/api/fhd/ai-tier/status` 和 `/api/fhd/ai/models` 没有当前源码定义；本轮 b970 原生后端均返回 404。终端状态应读取当前真实接口，并明确区分未提供查询能力。`/api/desktop/models` 仅代表本地模型目录，不能称为云模型注册表或已验证可推理模型。

原代码草稿服务仍有未接通的模型调用；CLI 应保留真实失败结果，不能把接口声明的能力当成实际成功。代码编辑服务按服务端 `WORKSPACE_ROOT` 处理路径，P2 应用仍依赖原提升口令。既有提案存储不是多人隔离的代码协作服务，本次迁移不能宣称获得了多租户沙箱。

登录从终端获取密码并建立独立会话，不读取浏览器凭据；会话文件按目标服务隔离并限制本地读取权限。命令失败应返回非零退出码，写入结果不明时不得自动重试。应用修改必须由明确命令确认。

## 验收要求

1. 实际前端路由和菜单均不再展示智脑，旧地址可以安全离开；主对话及生态页仍可达。
2. CLI 帮助、登录、退出、单次命令及交互模式可用；不在输出或命令参数里回显密码、会话或提升口令。
3. 对隔离完整后端登录，读取真实状态与接口目录；不存在或降级的数据明确显示原因。
4. 在隔离代码工作区完成读取、提案、差异、明确应用和实际文件读回；未授权、冲突及重复应用正确失败。
5. 客户端传输、身份文件、错误处理与前端退休均有针对性回归。新提交、CI、桌面制品和实际 UI 分别记录，不借用旧构建放行。

本页记录范围与验收合同；完成结果另行补充，不代表已经部署或替换用户的安装版本。
