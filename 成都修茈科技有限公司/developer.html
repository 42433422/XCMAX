SDK 2.0 manifest + hook

Dual Release

一套包，两种发布

同一个开发包既能作为功能 Mod 安装进客户工作台，也能上架为 AI 员工，由 manifest 的 release_targets 决定。

Mod 功能扩展

为客户的产品、订单、出货、客服等业务页提供新能力，挂接宿主事件与业务工作台。

  • 能力声明与宿主版本兼容校验
  • 事件 hook 支持优先级与一次性订阅
  • 卸载时自动清理资源

AI 员工

声明模型、提示词与可调用工具，把行业知识做成会执行任务的 AI 员工。

  • 模型与提示词声明
  • 可调用工具链定义
  • 任务执行与结果返回

mod + ai 双发布

release_targets: ["mod","ai"]，一次开发同时面向功能与 AI 两个上架目标。

// manifest.json { "id": "my-mod", "release_targets": ["mod", "ai"], "ai_manifest": { "model": "xcauto-account", "tools": ["search", "calc"] } }

SDK 2.0

manifest、hook 与事件通信

通过声明式 manifest 与事件 hook 对接宿主；对外接口保持稳定，便于版本演进。

声明式 manifest

能力声明、宿主版本兼容区间、双发布目标与 AI 清单，安装前即可校验。

  • 能力声明（capabilities）
  • 宿主版本兼容（host_version）
  • 双发布目标（release_targets）

事件 hook

订阅业务事件，支持优先级排序、一次性订阅与返回值收集，卸载时自动清理。

  • 事件订阅（on/once）
  • 优先级排序（priority）
  • 返回值收集（emit）

NeuroBus 事件通信

经 NeuroBus 发布业务事件，与宿主事件总线对齐，跨 Mod 协作有据可循。

  • 12 域事件总线
  • DEDUP + CIRCUIT + RATE_LIMIT
  • TRACE + LIFELINE + DLQ_AUTO

灰度发布

按比例与用户标签放量，观察稳定后逐步全量，异常一键回滚，降低上新风险。

  • 比例分桶 + 标签命中
  • 全量 / 暂停 / 回滚
  • 实时监控数据

评价与口碑

用户可对商品评分与评论；作者可在市场内回复。

  • 评分聚合与展示
  • 作者回复与互动
  • 口碑沉淀

收益结算

按成交计算分成，平台对账后结算并支持提现，收益明细清晰可查。

  • 成交分成（默认平台 30%）
  • 对账结算与提现
  • 收益明细报表
